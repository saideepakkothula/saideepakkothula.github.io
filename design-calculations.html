Design Calculations

This section is for engineering calculation tools. The first module is an IEEE Std 80 earthing design calculator, which opens a dedicated GUI page for entering project parameters and viewing preliminary grounding results.

IEEE 80 Earthing Calculation

Use the calculator to enter fault current, clearing time, soil resistivity, grid dimensions, and surface layer data. The next page will calculate key grounding indicators such as grid area, estimated grid current, approximate grid resistance, ground potential rise, and allowable touch and step voltages.

Design workflow: field data, conductor sizing, touch and step criteria, initial design, grid resistance, grid current, mesh and step voltage checks, then final detail design.
